本目录用于保存**尚未进入生产链路、但具有论文/科研潜力的长期创新候选**。它不是实验流水账，也不是生产契约；一次性实验日志仍放 `outputs/experiments/`，普通调研仍归档到 `docs/archive/`。

## 分类

- `training/`：训练机制创新，例如训练期特权信息、知识蒸馏、多任务监督、样本重加权、课程学习。
- `multi_resolution/`：跨分辨率建模，例如96点高频信息向24点业务目标的桥接、一致性学习与条件聚合。
- `target_design/`：预测目标与监督形式设计，例如价差方向分类、区间分类、回归+分类多任务。
- 后续只有形成明确长期方向时再增加其他分类，不为一次实验堆目录。

## 晋级规则

创新候选只有同时满足以下条件，才考虑进入正式设计或论文主创新：

1. **最终指标只在山东数据集上判定**；外部数据集只能用于预训练、方法验证或机制参考，不能替代山东测试成绩。
2. 推理阶段严格不读取目标答案或正式预测时不可获得的真实量；训练阶段允许使用明确标注为 privileged 的历史信息。
3. 至少有一个冻结测试段上的可复现提升；重要候选应尽量在两个时间块复验。
4. 记录基线、上限、消融、失败模式和信息边界，不能只保留最好数字。
5. 进入生产链路前必须由用户确认，并重新走正式回归和链路验收。
