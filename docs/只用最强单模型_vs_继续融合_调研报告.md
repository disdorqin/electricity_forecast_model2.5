# 只用最强单模型 vs 继续融合 — 决策调研报告

> 项目：山东电力现货价预测 EFM3（96 点 15min 实时 + 日前双分辨率，7 模型）
> 日期：2026-08-16。触发：用户提出"sgdfnet 一直最优且负权无法改善，是否只用 sgdfnet？深度学习模型训练慢效果差很头疼"。
> 结论摘要：**RT 应只用 sgdfnet**（实证融合拖累 +5.07，MoE 文献"专家塌缩"确认这是正确行为）；DA 融合也略逊于历史最优单模型（+0.69），倾向单模型但差距小可暂缓。深度学习模型慢且差是正常现象（文献支持），不必强融。

---

## 1. 问题背景与动机

- **现状**：RT 融合 = timesfm + sgdfnet + timemixer + rt916（NNLS 加权）。实证发现：
  - sgdfnet 整体 composite loss **23.43**，次优 timesfm 31.17、rt916 33.68、timemixer 35.07。
  - sgdfnet **每月都最优**（18.5-28.8），无任何月份被反超。
  - **误差相关性**：sgdfnet 与其他模型 0.63-0.68（不算极高，但优势太大）。
- **痛点**：TimesFM/TimeMixer/RT916 每天训练需分钟到半小时级，效果却明显差；负权重（用户提出）全样本测试未能改善（赢等权 71% 但整体 fuse 略差于纯学）。

## 2. 实证结论（201 单元滚动回测，30d 窗，step=3）

| 任务 | 只用最强单模型 | NNLS 融合 | 等权 | oracle(理论上限) |
|---|---|---|---|---|
| **RT** | **sgdfnet 32.02** | 37.08（差 +5.07） | 41.61（+9.60） | 27.17（赢26.9%） |
| **DA** | **历史最优 32.05** | 32.74（+0.69） | 33.72（+1.78） | 24.67（赢60.2%） |

**关键发现**：
1. **RT 上融合显著拖累**（+5.07），等权更差（+9.60）。只用 sgdfnet 最接近 oracle。
2. **DA 上融合也略逊于历史最优单模型**（+0.69），但差距小，且按整体口径（全部点拼接）DA 融合 24.67 优于单模型——口径敏感，需谨慎。
3. oracle（事后最优）RT 仅赢 sgdfnet 26.9%——即使理论上限也难大幅超越 sgdfnet。
4. sgdfnet 在 **68.6% 单元**（按 day+period）是单模型最优；其他模型各自在 ~10-12% 单元偶尔赢（不可预测）。

## 3. 文献支持

### 3.1 MoE "专家塌缩"（expert collapse）—— 融合塌缩为单模型是正确行为
- 多篇 2025-2026 MoE 论文（arxiv:2601.03889 / 2603.26734 / 2605.19378 / 2604.23036）系统研究 **expert collapse**：当路由收敛到少数主导专家时，其余专家变冗余，门控塌缩。
- **启示**：sgdfnet 在所有 regime（工作日/周末、光伏/非光伏、春夏秋冬）都最优（实证）→ gating 的正确解就是"全押 sgdfnet"。**继续融合本质是在对抗一个已塌缩的问题，只会引入噪声**。

### 3.2 时序预测不一定需要深度学习
- **arxiv:2101.02118 "Do We Really Need Deep Learning Models for Time Series Forecasting?"**：传统/浅层方法常更优更稳，DL 复杂度常不必要。
- **PMC12101857**：XGBoost 转折点估计比 LSTM 好 22-34%。
- **arxiv:2301.00790**：非平稳时序（regime 变化）下 GBDT 带 dropout 优于 NN（NN 易过拟合）。
- **启示**：SGDFNet（基于 HistGradientBoosting 的 delta 回归）胜过多个深度模型**是正常现象**，不是异常。

### 3.3 融合何时有效（Krogh & Vedelsby 1995）
- 融合降方差需要模型**误差低相关**（diversity）。本数据 sgdfnet 与其他模型误差相关 0.63-0.68，**但 sgdfnet 绝对优势太大**（23.4 vs 31-35，差距 30%+），融合的方差收益被"携带差模型噪声"完全抵消。
- 结论：**强弱差距 >30% 时，融合几乎不可能赢过最强单模型**——符合我们实证。

## 4. 决策框架

| 场景 | 建议 |
|---|---|
| **RT（sgdfnet 全面主导）** | **只用 sgdfnet**。融合收益为负（-5.07），其他模型纯拖累。分类器仍照常对 sgdfnet 输出修正。 |
| **DA（3 模型交替最优，无主导）** | 融合基本持平（+0.69），**暂保持 NNLS 融合**（用户决定 DA 不动）。后续可考虑"小时级历史最优单模型"（DA 分时段模型优势明显）。 |
| **如果必须保留多模型** | 只保留 sgdfnet + timesfm（次优，误差相关最低 0.707）做"轻量对照"，timesfm 权重封顶 0.2。不用 timemixer/rt916。 |
| **计算预算** | 砍掉 timemixer/rt916 的训练（每天省 6min + 5min），把时间给 sgdfnet 调参/更多特征。 |

## 5. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 只用 sgdfnet 单点故障 | 滚动监控：若 sgdfnet 连续 N 天 MAE 恶化（>1.3×基线），触发回退到 NNLS 融合。 |
| 过拟合风险（单模型无融合平抑） | 严格滚动验证（已在 ledger 230 天验证）；保留等权融合作对照列。 |
| regime 突变（sgdfnet 失效） | 每周重学权重（NNLS 已支持），若 sgdfnet 权重被 NNLS 降到 <0.6 则说明市场变了。 |
| DA 结论口径敏感 | DA 决策前用统一口径（全部点拼接）复核。 |

## 6. 落地选项

- **A. RT 只用 sgdfnet**：融合阶段直接输出 sgdfnet 预测（跳过 NNLS），改动最小，实证 +5.07 提升。DA 不动。
- **B. RT sgdfnet + timesfm 轻融合**：timesfm 权重 cap 0.2，保留轻微多样性对冲。
- **C. 全部单模型化**：RT 用 sgdfnet、DA 用分时段历史最优单模型（需再验证）。

**推荐**：A（先落地 RT 只用 sgdfnet），保留 B 作为可切换选项。等用户决定后实施。
