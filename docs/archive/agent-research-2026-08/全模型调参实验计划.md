## 一、调参顺序（按训练时间短→长）

| 优先级 | 模型 | 设备 | 预计单次训练 | 决策 |
|---|---|---|---|---|
| **1** | **lightgbm** | CPU 本机 | **<0.1s/配置** ✅ 已验证 | 先调（已完成首轮） |
| **2** | **sgdfnet** | CPU 本机 | ~秒级~分钟级（待测） | 先测一次，>3min 则停 |
| **3** | **timesfm** | CPU 本机 | 零样本/微调头（待测） | 主要调"微调 vs 零样本" |
| **4** | **timemixer** | GPU 服务器 | ~分钟级 | 服务器跑，小窗先测 |
| **5** | **rt916** | GPU 服务器 | ~分钟级 | 服务器跑，小窗先测 |

**规则（用户立规）**：
- 训练时间短的模型**先调**（lightgbm/sgdfnet 本机可做）
- 某个模型**第一次测试时间很长（如 >3min）就先停**，不硬调
- GPU 模型先在服务器用小窗 smoke 测耗时，再决定调参策略

## 三、统一调参方法论（每个模型）

### 3.1 超参网格（通用维度）
| 维度 | 候选 | 说明 |
|---|---|---|
| 学习率 | 0.02 / 0.03 / 0.05 / 0.10 | LightGBM 已验证 lr02 优 |
| 模型容量 | 浅 / 中 / 深（如 leaf 15/31/63/127） | 防过拟合 vs 拟合精细 |
| 迭代数 | 1000 / 2000 / 3000 / 4000 | 配合 early stopping |
| 特征子集 | 全量 / 去长尾 / 加时段交互 | 与特征预计算联动 |

### 3.2 对比维度（用户要求）
1. **MAE / MSE / SMAPE**（生产口径：先 clip 值到 50 再算）
2. **loss 收敛**：best_iteration + val loss 轨迹
3. **训练时间**：每配置秒数

### 3.3 指标口径铁律（本轮教训）
- **SMAPE 必须用生产公式**：`值<50→50` 再算 `|p-t|/((|p|+|t|)/2)`
- 不是"分母 floor50"——两者对负价+尖峰数据差异巨大（平段 0.21 vs 0.73）
- 所有实验脚本统一从 `lightGBM/train_fix.calculate_smape` 提取公式

## 四、分模型计划

### 4.1 lightgbm（✅ 首轮完成，待扩大复验）
- 首轮：B 配置（lr02_leaf63）三时段全优，↓1.5-2.0%
- **下一步**：扩到 6 个月窗复验；B vs 当前生产默认 A 做正式对比

### 4.2 sgdfnet（CPU，次调）
- 训练入口：`SGDFNet/src/sgdfnet/`（HistGradientBoosting）
- 可调：max_iter、learning_rate、max_depth、l2_regularization
- 先测 1 次训练耗时，>3min 停

### 4.3 timesfm（CPU，零样本为主）
- 主要对比：**零样本** vs **微调轻量头** vs 冻结主干
- 可调：horizon、context 长度、是否微调
- 训练时间天然短（零样本）

### 4.4 timemixer / rt916（GPU 服务器）
- 服务器小窗 smoke 测耗时 → 决定是否调
- 可调：epochs、learning_rate、batch_size、hidden_dim
- 用 `--smoke-*` 参数族先行

## 五、验证流程（每模型）

1. **数据窗**：先 2 个月（2026-04~05，与 lightgbm 一致）→ 稳定后扩 6 个月
2. **对照**：该模型 A(生产默认) vs 候选配置，同数据同窗口
3. **验收**：
   - SMAPE/MAE/MSE 改善（生产口径）
   - 训练时间不显著增加（或可接受）
   - 扩窗后结论稳定
4. **回归**：4 件套 + 黄金基线 diff（接入生产前）
