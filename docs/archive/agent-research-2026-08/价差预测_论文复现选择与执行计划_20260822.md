## 0. 结论先行

当前不建议继续无差别复现新的通用时序网络。下一阶段应优先复现**直接以 DA/RT spread 为目标**、且能够与我们现有 Feature Cube、14:00 信息边界和 P6/SGDFNet 互补结构结合的方法。

本报告建议：

1. **必做 R1：山东三状态 Regime + Quantile Regression / State-Probability Regression**  
   来源：Wang et al. (2026), *Risk-Aware Trading Signals for Smart Aggregators in Multi-Time-Scale Electricity Markets Using Regime-Switching and Tail-Risk Analysis*。  
   这是目前最接近我们的论文：山东、2024、15 min、目标就是 DA/RT spread。

2. **必做 R2：DART Spike Statistical Learning（优先 GBDT/Logistic）**  
   来源：Galarneau-Vincent et al. (2023), *Foreseeing the worst: Forecasting electricity DART spikes*，Energy Economics。  
   目的不是替代整个连续回归器，而是补齐我们目前最明显的“正/负尾部状态识别”能力，再把 tail probability 作为单模型输入或修正信号。

3. **条件复现 R3：Covariate-Dependent Three-Regime Mixture Distribution**  
   来源：Forgetta et al. (2025), *Distributional forecasting of electricity DART spreads with a covariate-dependent mixture model*，Energy Economics。  
   只有当 R1/R2 证明 regime/tail probability 在山东数据上确实能提高 balanced direction 或 1–8 正价差识别时再实现。它更完整，但实现成本也更高。

暂时**不优先**复现 PJM Seq2Seq/BiLSTM 或 ERCOT Transformer。它们会进入候选库，用于当统计/regime路线不足时再补一个深度模型对照。

## 2. 为什么现在先复现这三条，而不是再找一个新 SOTA 网络

筛选标准不是期刊影响因子或网络复杂度，而是六项：

1. **目标相同**：直接预测 `DA/RT spread`、spread sign、spread spike 或 distribution；
2. **市场相近**：山东优先，其次同样两结算现货市场；
3. **信息合同可适配**：不能依赖我们在 D-1 14:00 时拿不到的信息；
4. **与当前失败模式互补**：优先解决 positive/negative regime、1–8、spike/tail；
5. **训练/复现成本可控**：优先 CPU 统计模型和树模型；
6. **结果可证伪**：每个模块都能单独 A/B，而不是整套黑盒一次替换。

按这六项，R1 > R2 > R3 > 深度 Seq2Seq/Transformer。

# 3. R1：山东 Regime + Quantile Regression —— 第一优先级

## 3.1 论文

Wang, S.; Zhang, H.; Liu, D.; Wang, S.; Huang, H. (2026).  
**Risk-Aware Trading Signals for Smart Aggregators in Multi-Time-Scale Electricity Markets Using Regime-Switching and Tail-Risk Analysis.**  
Energies 19(15), 3592.  
Publisher: https://www.mdpi.com/1996-1073/19/15/3592  
DOI: https://doi.org/10.3390/en19153592

## 3.2 为什么它必须先做

论文数据：

- 山东电力现货市场；
- 2024 年；
- 15 min；
- 35,136 个非公开观测；
- spread 定义就是 DA/RT 跨市场价差（论文符号方向需复现时统一到我们的 `RT - DA`）。

论文识别三种状态：

1. negative-deviation / high-volatility；
2. near-zero / low-volatility；
3. positive-deviation。

核心预测部分包含：

- Markov regime-switching；
- quantile regression；
- linear regression；
- linear regression + lagged state probabilities；
- tail-risk signal。

公开结果中：

- Quantile Regression 点预测 MAE = **24.015 CNY/MWh**，RMSE = 49.673；
- linear + lagged state probabilities 的 RMSE = **46.745**；
- 去掉 lagged spread 后 MAE 从 24.015 恶化到 **54.278**；
- December OOS 上 upper/lower tail signal recall = **0.872 / 0.841**。

这些指标不能与我们的 SCR/signed-sMAPE直接横比，但论文给出了一个极强信号：

> **spread 的短期状态持续性和 lag 信息是核心；state probability 与 quantile/tail signal 有独立价值。**

## 3.3 论文原始变量到我们数据的映射

| 论文变量 | 我们的可用映射 | 可得性 | 处理 |
|---|---|---|---|
| lagged spread | D-2/D-3/D-7、rolling、D-1 p1–p14 context | safe | 绝不能直接使用 D-1 p15–p24 真值 |
| provincial load | `直调负荷预测值` | target forecast | 保留逐小时槽位 |
| 15-min/hourly load change | `ramp_load` | target forecast | Feature Cube 已有 |
| day-ahead price | 当前 spread v3 合同不允许 target-day DA 进入 | **禁止** | 本项目不照搬该项 |
| month/intraday/weekend | hour/dow/calendar | predetermined | 可用 |
| regime state probability | 新建 | cutoff-safe | 用历史 spread + 截止14:00状态推演 |

因此我们做的是**业务合同适配复现**，不是假装“完全复刻原论文数据口径”。

## 3.4 关键创新适配：14:00 后不能使用 lag1，怎么处理？

这是本复现最重要的设计。

论文高频预测可以使用近期 spread lag，而我们预测 D 日整天时不能看到 D-1 14:00 后的 spread。因此不允许简单照搬 `lag1`。

建议设计两类严格安全信息：

### A. Cutoff state

在 D-1 14:00 用可见的 p1–p14 spread 得到当前 regime posterior：

`P(S_cutoff = negative / neutral / positive | available history)`

### B. Markov state propagation

拟合历史转移矩阵 `P` 后，对未来目标槽位进行状态概率传播：

`pi(h) = pi(cutoff) @ P^h`

如果数据支持，可以进一步做：

- 按 hour/segment 的 transition matrix；
- weekday/weekend transition；
- high-renewable / normal transition。

**但第一版只做全局三状态 transition，避免复杂化。**

于是即使 D-1 p15–p24 和 D 日实际 spread 未发生，模型仍然能获得：

- `regime_prob_neg[h]`
- `regime_prob_neutral[h]`
- `regime_prob_pos[h]`
- `expected_regime_duration`
- `state_entropy[h]`

这很可能比当前 p15–p24 单纯 rolling-median proxy 更有结构意义。

## 3.5 R1 实际复现内容

不是只做一个模型，而是做三层 A/B：

### R1-A：Causal Quantile Regression

输入：

- P6 的核心输入包；
- cutoff-safe spread lags/context；
- load/ramp/fundamental；
- 暂时不加 state probabilities。

输出：

- q05 / q10 / q50 / q90 / q95；
- q50 作为连续点预测；
- quantile crossing 做最简单单调修正。

用途：验证“分布预测”是否比只做 MAE 回归更适合 spread。

### R1-B：Markov Regime + State Probability

先只做状态模型，不改连续预测器。

输出每个目标小时的三状态概率，并单独评价：

- positive regime recall；
- negative regime recall；
- balanced state classification；
- 1–8 positive recall。

### R1-C：State-Augmented P6 / Quantile

将 state probabilities 当作输入，而不是做 hindsight gate：

`P6 features + regime_prob_* -> one classifier/regressor`

这仍然是**单模型输入增强**，不是融合器。

## 3.6 R1 成功判定

第一优先级指标：

- raw SCR；
- positive accuracy；
- negative accuracy；
- balanced direction accuracy；
- 1–8 positive accuracy；
- 1–8 balanced；
- MAE；
- signed spread sMAPE；
- quantile Pinball Loss（R1-A）。

进入下一轮的最低条件：

- overall balanced ≥ 61%；**或**
- 1–8 positive 从当前 20% 提升到 ≥35%，同时 1–8 balanced 不低于当前；**或**
- 在不明显牺牲 P6 总 SCR 的情况下，positive recall 提升 ≥8 个百分点。

如果只是 raw SCR 因更多预测负类而上涨，不算成功。

## 3.7 预计成本

- Markov：CPU，秒级～分钟级；
- Quantile Regression：CPU，秒级～分钟级；
- 适合首先完成完整 walk-forward；
- 不需要 GPU。

# 4. R2：DART Spike Statistical Learning —— 第二优先级

## 4.1 论文

Galarneau-Vincent, R.; Gauthier, G.; Godin, F. (2023).  
**Foreseeing the worst: Forecasting electricity DART spikes.**  
Energy Economics 119, 106521.  
Publisher: https://www.sciencedirect.com/science/article/pii/S0140988323000191  
Preprint/working paper: https://www.gerad.ca/en/papers/G-2022-26  
DOI: https://doi.org/10.1016/j.eneco.2023.106521

## 4.2 为什么值得复现

它研究的不是普通 DA/RT price，而是**DART spread spike probability**。

论文把 spike forecasting 直接做成监督分类问题，并比较：

- Logistic Regression；
- Random Forest；
- Gradient Boosting Trees；
- DNN。

关键发现是：

> 结果对具体算法相对稳健，**tailored feature set 比“选哪个模型名字”更重要**；Gradient Boosting 稍好。

论文重要特征包括：

- load forecast / transfer-capacity ratio；
- predicted heating/cooling degree days；
- seasonal/hour/month；
- 最近 24h spike count。

这与我们 Feature Cube 的结论高度一致：

- `bidding_space_ratio`
- `interconnect_share`
- `wind_share`
- `ramp_*`
- `forecast_error_*`
- `current 14:00 regime`

本身比继续加深网络更有价值。

## 4.3 我们不做“只预测极端值”的孤立模块

第一步先忠实复现思想：

建立两个 cutoff-safe 标签：

- `positive_spike = spread > train-only threshold_high`
- `negative_spike = spread < train-only threshold_low`

阈值只从当前训练窗口计算，禁止用全数据 q95/q05 造成未来信息泄漏。

候选阈值只固定两种，不扫大量参数：

- train q90/q10；
- train q95/q05。

模型：

- Logistic Regression（解释性基线）；
- LightGBM Classifier（主要复现对象）。

## 4.4 第二阶段：把 tail probability 变成“单模型特征”

如果 R2 能稳定识别正/负 tail，则把：

- `p_positive_spike[h]`
- `p_negative_spike[h]`
- `tail_risk_gap = p_pos - p_neg`
- `tail_uncertainty`

加入 P6，而不是直接规则强行改预测值。

这样仍然保持：

`Feature Cube -> 单个最终 classifier/regressor`

符合当前“先提高单模型，不急着做融合”的阶段目标。

## 4.5 为什么它可能专门帮助 1–8

当前 P6 在 1–8：

- positive recall 20%；
- negative recall 82.67%。

这说明模型对“凌晨异常正 spread”几乎没有触发器。

R2 将专门检查：

- wind forecast error；
- overnight wind ramp；
- bidding-space tightness；
- recent positive-spike count；
- current 14:00 state；
- D-2/D-7 overnight spread state；

是否能形成一个“正 tail 发生概率”。

如果 1–8 positive recall 提升明显，即使连续 MAE 未立即下降，也有很高价值。

## 4.6 成功判定

独立评价：

- positive-tail PR-AUC / recall / precision；
- negative-tail PR-AUC / recall / precision；
- Brier score；
- false alarm rate。

加入 P6 后再看：

- overall SCR；
- balanced；
- 1–8 positive；
- 1–8 balanced。

成功门槛：加入 tail probabilities 后，相对 P6：

- overall balanced +1.5pp 以上；**或**
- 1–8 positive +10pp 以上且 overall SCR 不下降超过1pp。

## 4.7 预计成本

由于 Feature Cube 已存在，LightGBM/Logistic 单组测试应是秒级～几十秒级；这是当前 ROI 最高的复现任务之一。

# 5. R3：Covariate-Dependent Three-Regime Mixture —— 条件复现

## 5.1 论文

Forgetta, A.; Godin, F.; Augustyniak, M. (2025).  
**Distributional forecasting of electricity DART spreads with a covariate-dependent mixture model.**  
Energy Economics 144, 108332.  
Publisher: https://www.sciencedirect.com/science/article/pii/S0140988325001562  
SSRN: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4673749  
DOI: https://doi.org/10.1016/j.eneco.2025.108332

## 5.2 模型思想

不是把 spread 当成单峰高斯变量，而是假设存在三个分布 regime：

1. regular regime：Gaussian；
2. positive spike regime：Generalized Pareto Distribution；
3. negative spike regime：Generalized Pareto Distribution。

更重要的是：

- regime mixing probability 随 covariates 变化；
- positive/negative spike severity 也随 covariates 变化；
- covariates 包括 load/weather/gas forecasts；
- 论文发现：把 covariates 放进 **severity component** 尤其重要；
- deep quantile regression benchmark 没有超过其 mixture model。

这是一个非常适合我们 spread 重尾、负值、正负 spike 的模型家族。

## 5.3 与我们的映射

我们没有天气和天然气价格，不允许假装完全复现。

第一版只使用现有严格可得 fundamentals：

- load forecast；
- wind/solar/new-energy forecast；
- bidding space；
- residual load；
- renewable share；
- ramps；
- forecast-error states；
- current spread regime；
- calendar。

核心不是复刻其 NYISO covariates，而是复刻：

> **“regular / positive spike / negative spike 三分布 + covariate-dependent frequency/severity”这一建模假设。**

## 5.4 为什么不是现在立刻做

它的工程成本明显高于 R1/R2：

- mixture likelihood；
- GPD tail threshold；
- 参数约束；
- 稳定优化；
- distribution calibration；
- 多个概率输出。

如果 R1/R2 连“regime/tail probability 是否能改善方向”都没有证明，则没有必要先实现完整 mixture。

触发条件：

> R1 或 R2 至少一个在历史 walk-forward + recent benchmark 上产生稳定、非先验型增益。

满足后再进入 R3。

# 7. 执行顺序：真正开始复现时怎么做

## Phase 0 — 冻结实验合同

在写任何模型前固定：

- target：`spread = RT - DA`；
- resolution：24点 hourly 第一版；
- cutoff：D-1 14:00；
- target-day DA 不进入 spread 输入（遵守当前 v3 合同）；
- target-day actual/RT/spread 只作标签；
- target-day grid forecast 可用；
- forecast-error 只能 D-2 或更早；
- Feature Cube 继续复用 `spread_feature_cube_v1_20260821`，如新增 state/tail 特征则生成 v2，不改 v1。

### 评估窗口建议

由于 2026-07-31～08-14 已经被我们打开过，不再称“pristine holdout”。新论文复现采用：

1. **Historical OOS**：选一个更早、未作为本轮模型选择依据的长窗口做 walk-forward；
2. **Recent Benchmark**：固定参数后一次性跑 2026-06-16～08-14，作为与 P6/SGDFNet 的统一对照；
3. 不允许看 Recent Benchmark 后再为该窗口反复调阈值。

模型参数优先来自论文；必须调参时只允许极小结构 A/B。

# 8. 统一验收标准

任何新论文模型都必须报告：

- Direction Accuracy / SCR；
- Positive Accuracy；
- Negative Accuracy；
- Balanced Direction Accuracy；
- MAE；
- RMSE；
- signed spread sMAPE；
- 1–8 / 9–16 / 17–24 分时段；
- 每日波动；
- 最差日；
- 对 tail 模型额外报告 Precision / Recall / PR-AUC / Brier；
- 对 quantile 模型额外报告 Pinball Loss / coverage。

基线至少包含：

- rolling median；
- P6 Feature-LGBM；
- SGDFNet；
- TimeMixer unified24。

### “值得继续”的定义

不得因为单个 raw SCR 高就认定成功。

优先级：

1. balanced；
2. 1–8 positive；
3. overall SCR；
4. 连续 spread MAE/sMAPE；
5. tail calibration。

当前阶段如果一个新模型能稳定做到：

- SCR ≥ 64%；
- balanced ≥ 62%；
- positive/negative 都 ≥50%；

就已经值得进入下一轮单模型精调。

真正达到或逼近 70% 后，再做多 seed / 稳定性正式验收。

# 10. 最终执行建议

下一次重新开始实验时，不需要再重新讨论模型池，直接按：

**R1 山东 Regime/Quantile → R2 DART Spike → 决策是否 R3 Mixture。**

这一顺序的目的不是“把三篇论文都复现完”，而是逐步回答三个核心问题：

1. **山东 spread 是否真的存在可预测、可传播的正/负 regime？**
2. **我们的 1–8 正价差失败，是否可以通过 tail/spike probability 识别？**
3. **如果 regime/tail 有效，是否值得把 spread 从单点回归升级为完整 distributional model？**

只要前两步能把 P6 的 `63.33% SCR / 60.76% balanced` 推到一个稳定的新台阶，就暂停继续找模型，转而深挖该机制。

这比继续逐个复现通用时序 SOTA 更符合当前项目目标。
