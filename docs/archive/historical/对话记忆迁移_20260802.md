## 一、项目是什么
山东电力现货价格预测交付链路 v2.5。已有 24 点（小时级）7 模型预测 + Ledger 自适应权重融合 + 负电价分类器的完整交付主线（2026-07-03 正式陪跑验收 PASS）。当前核心任务：**新增 96 点（15 分钟级）价格预测兼容主线**，满足甲方要求。

## 二、技术栈与结构
- 7 模型：日前链路 lightgbm/timesfm/timemixer；实时链路 timesfm/sgdfnet/timemixer/rt916。五阶段 `ledger_predict→ledger_weight→ledger_fuse→ledger_classifier→final_outputs`，输出 `submission_ready.csv`。GPU 环境 conda `epf-2`，日前/实时串行、部分模型 GPU。
- 96 点新层：`utils/resolution.py`（Resolution 抽象：hourly/15min，`business_period` 替代 `hour_business`），独立 `ledger_96`，预测产物落 `output/prediction_96/`。设计见 `docs/PLAN_96_POINT_MINIMAL_CHANGE.md`。
- 数据：国网 PMOS 爬虫打包 exe（auto_fill_96 / backfill_actual_96 / backfill_unit_96），云端 MySQL（`epf_market_data_96` 特征 + `epf_unit_data_96` 价格），本地镜像 + `build_96_full_table.py` 宽表。

## 六、已知问题 / 约束 / 踩过的坑
- LightGBM 目标日 NaN→NoneType（已修）；SGDFNet da_anchor NaN 用中位数 fallback；hour_business 必须严格 `{1..24}`。
- 96 点实际值曾与 24 点不对应/缺列/错位；96 点价格为单机组出清价 `da_cq_price/rt_cq_price`，口径不同于 24 点全省均价（见 `docs/24_VS_96_FEATURE_COMPARISON.md`）。
- Windows JSON 需显式 UTF-8（否则 gbk 报错）；权重学习需最近 30 个完整训练日（当前 ledger 有空窗）。
- 公司电脑无环境必须打包 exe；爬虫需 config.json+.env 同目录，Cookie 过期会 HTTP 911/CSRF 报错。
- 铁律：最小改动、不碰 24 点主线（加 `resolution=HOURLY` 默认参数）。
